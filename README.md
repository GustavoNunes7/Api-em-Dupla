## 📖 Descrição do Projeto
O **Movie Explorer** é uma aplicação web composta por **backend e frontend** que consome uma **API externa de filmes**.

A aplicação permite que os usuários **pesquisem filmes por gênero** (exemplo: Ação, Comédia, Terror, etc.).

O **backend** é responsável por realizar a comunicação com a API externa e enviar os dados para o frontend.

O **frontend** recebe esses dados e os exibe de forma organizada para o usuário.

### 🎯 Objetivo do Projeto
Praticar:

- Integração entre **frontend e backend**
- Consumo de **APIs externas**
- Organização de um **projeto web completo**
- Manipulação de **dados retornados por APIs**

## ⚙️ Instruções para Executar o Backend

1. Clone o repositório:

```bash
git clone [link-do-repositorio]
```

2. Entre na pasta do projeto:

```bash
cd Api-em-dupla
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o servidor:

```bash
node server.js
```

O backend será iniciado em:

```
http://10.106.208.36:${PORT}
```

---

## 💻 Instruções para Executar o Frontend

1. Abra a pasta do projeto.

2. Localize o arquivo:

```
index.html
```

3. Abra o arquivo em um navegador (Google Chrome, Edge, etc.).

Ou utilize uma extensão como **Live Server** no **VSCode** para executar o projeto.
